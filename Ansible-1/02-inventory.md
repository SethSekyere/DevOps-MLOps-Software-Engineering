# 📦 Inventory in Ansible

An **Ansible inventory file** is a foundational component used to define the hosts (remote systems) you want to manage, along with the groups to which those hosts belong. It serves as a source of truth for Ansible to determine which nodes to communicate with during automation tasks.

Inventories can be either **static** (a simple text file) or **dynamic** (generated by a script or plugin).

---

## 📘 Static Inventory

A static inventory is a manually maintained file, typically named `hosts` or `inventory`, and can be written in **INI** or **YAML** format.

### 🔹 INI Format

```ini
# inventory file: hosts

[webservers]
web1.example.com
web2.example.com

[dbservers]
db1.example.com
db2.example.com

[all:vars]
ansible_user=admin
ansible_ssh_private_key_file=/path/to/key
```

### 🔸 YAML Format

```yaml
# inventory file: hosts.yaml

all:
  vars:
    ansible_user: admin
    ansible_ssh_private_key_file: /path/to/key
  children:
    webservers:
      hosts:
        web1.example.com:
        web2.example.com:
    dbservers:
      hosts:
        db1.example.com:
        db2.example.com:
```

## 🔄 Dynamic Inventory

A **dynamic inventory** is automatically generated by a script or plugin. This is particularly useful in environments where hosts frequently change, such as cloud-based infrastructures (AWS, GCP, Azure, etc.).

Below is an example of a Python script that dynamically generates an inventory from AWS EC2:

```python
#!/usr/bin/env python

import json
import boto3

def get_aws_ec2_inventory():
    ec2 = boto3.client('ec2')
    instances = ec2.describe_instances()
    
    inventory = {
        'all': {
            'hosts': [],
            'vars': {
                'ansible_user': 'ec2-user',
                'ansible_ssh_private_key_file': '/path/to/key'
            }
        },
        '_meta': {
            'hostvars': {}
        }
    }

    for reservation in instances['Reservations']:
        for instance in reservation['Instances']:
            if instance['State']['Name'] == 'running':
                public_ip = instance['PublicIpAddress']
                inventory['all']['hosts'].append(public_ip)
                inventory['_meta']['hostvars'][public_ip] = {
                    'ansible_host': public_ip
                }

    print(json.dumps(inventory, indent=2))

if __name__ == '__main__':
    get_aws_ec2_inventory()
```

---

## ▶️ Usage

To run a playbook or ad-hoc command using an inventory:

```bash
ansible-playbook -i inventory <adhoc-command-or-playbook.yml>
```

Or for dynamic inventory:

```bash
ansible-playbook -i ./dynamic_inventory_script.py <playbook.yml>
```
